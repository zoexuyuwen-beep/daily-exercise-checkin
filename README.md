# Daily Exercise Check-in

This is a simple browser-based app to log daily workouts and review history.

## Features
- LocalStorage-backed "database" storing all check-ins.
- Main page for submitting the current day's exercise.
- History page showing stats, filters, and deletion.

## Running
Open `index.html` in any modern browser. The history page at `history.html` reads the same local data.
